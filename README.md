# Лабораторная работа 1. GUI для языкового процессора

## Цель работы

Создание кроссплатформенного графического интерфейса для языкового процессора в виде текстового редактора / IDE.

## Автор

Даниил

## Описание проекта

Оконное приложение с меню и двумя основными рабочими областями: редактор кода с вкладками и нижняя панель вывода (Терминал, Вывод, Сборка). Реализованы вкладки для работы с несколькими файлами, нумерация строк, подсветка синтаксиса, запуск и отладка внешних программ. Поддержка проектов (открытие папки) и настраиваемых команд запуска. Подготовлена основа для подключения языкового процессора (генерация лексера JFlex).

## Используемые технологии

- **Язык:** Java 25  
- **GUI:** JavaFX 22  
- **Редактор кода:** RichTextFX 0.11.7  
- **Лексер:** JFlex 1.9.0 (генерация из `.flex`)  
- **Сборка:** Gradle 9.x  
- **Среда разработки:** любая (проект не привязан к IDE)

## Инструкция по сборке и запуску

### Требования

- **JDK 25** (для сборки и запуска).

### Запуск в режиме разработки

```bash
./gradlew run
```

На Windows:

```bat
gradlew.bat run
```

### Сборка проекта

```bash
./gradlew build
```

Сборка автоматически запускает генерацию лексера из файлов в `src/main/jflex/*.flex` (если они есть).

### Создание исполняемого JAR (опционально)

Используйте задачи Gradle для упаковки приложения (например, `jlink` или сторонний плагин). Для нативных бинарников под каждую ОС потребуется сборка на целевой платформе.

## Интерфейс и функции

### Главные элементы

- **Меню** (верхняя строка)
- **Область редактирования** (центральная часть): вкладки файлов, нумерация строк, подсветка синтаксиса
- **Боковая панель проекта** (опционально): дерево файлов при открытии проекта
- **Область вывода** (нижняя часть): вкладки **Терминал**, **Вывод**, **Сборка**
- **Строка состояния** (внизу): имя файла, строка/столбец, сообщения

### Меню «Файл»

| Действие           | Горячие клавиши        |
|--------------------|-------------------------|
| Создать            | Ctrl+N / Cmd+N          |
| Открыть            | Ctrl+O / Cmd+O          |
| Открыть проект     | Ctrl+Shift+O / Cmd+Shift+O |
| Сохранить          | Ctrl+S / Cmd+S          |
| Сохранить как      | Ctrl+Shift+S / Cmd+Shift+S |
| Автосохранение     | Ctrl+Shift+A / Cmd+Shift+A |

### Меню «Правка»

| Действие     | Горячие клавиши        |
|--------------|-------------------------|
| Отменить     | Ctrl+Z / Cmd+Z          |
| Повторить    | Ctrl+Shift+Z / Cmd+Shift+Z |
| Вырезать     | Ctrl+X / Cmd+X          |
| Копировать   | Ctrl+C / Cmd+C          |
| Вставить     | Ctrl+V / Cmd+V          |
| Удалить      | Delete                  |
| Выделить все | Ctrl+A / Cmd+A          |

### Меню «Пуск»

| Действие          | Горячие клавиши           |
|-------------------|----------------------------|
| Запустить debug   | Ctrl+F5 / Cmd+F5           |
| Запустить         | Ctrl+F6 / Cmd+F6           |
| Остановить        | Ctrl+Shift+F5 / Cmd+Shift+F5 |
| Настроить запуск  | Ctrl+Alt+R / Cmd+Alt+R     |

### Меню «Вид»

- **Настройки** — размер шрифта редактора и вывода, язык интерфейса (RU/EN/системный).

### Меню «Справка»

| Действие       | Горячие клавиши |
|----------------|------------------|
| Вызов справки  | F1               |
| О программе    | —                |

### Язык интерфейса

Переключение языка (RU/EN) в **Вид → Настройки** (поле «Язык интерфейса»).

## Ограничения

- Сохранение файлов выполняется в кодировке UTF-8.
- Запуск внешней программы привязан к выбранной корневой папке проекта и настраиваемым командам (сборка/запуск под конкретный язык или инструмент).
- Для нативных исполняемых файлов под Windows/macOS/Linux требуется сборка на каждой целевой ОС.

## Дополнительно реализовано

- Изменение размера шрифта в окне редактора и в области вывода (Вид → Настройки).
- Открытие файла перетаскиванием в окно программы.
- Строка состояния (имя файла, строка/столбец).
- Подсветка синтаксиса в редакторе (на основе RichTextFX и опционально JFlex).
- Горячие клавиши для основных команд.
- Вкладки для одновременной работы с несколькими файлами.
- Выбор языка интерфейса (RU/EN/системный).
- Нумерация строк в редакторе.
- Вкладки в области вывода: Терминал, Вывод, Сборка.
- Открытие проекта (папки) и боковая панель с деревом файлов.
- Настраиваемый запуск и отладка (корень проекта, команды запуска/отладки).
- Автосохранение (опция в меню Файл).
